Amazon Bedrock
GA カナダリージョン拡張 2026-10-30
Amazon Bedrock のクロスリージョン推論（CRIS）がカナダで利用可能に ─ Claude Sonnet 4.5・Haiku 4.5 を ca-central-1 ↔ ca-west-1 間でルーティング、データ主権を維持しながら可用性を向上
詳細を表示

AWSはAmazon Bedrockのクロスリージョン推論（Cross-Region Inference / CRIS）をカナダのAWSリージョンで有効化した。カナダ（ca-central-1）のクライアントからリクエストを発行すると、Anthropic Claude Sonnet 4.5・Claude Haiku 4.5が ca-central-1 と ca-west-1 の間で自動的にロードバランスされ、ピーク時の可用性と処理スループットが向上する。データはAWSグローバルネットワーク上のカナダのリージョン間のみで処理されるため、カナダのプライバシー法（PIPEDA等）への準拠が容易となる点が強調されている。金融・医療・政府機関など、データの地理的残留（Data Residency）要件が厳しい組織にとって有効な選択肢となる。これまでCRISは米国・EU・アジアパシフィックの主要リージョンが対象だったが、今回のカナダ展開でグローバルエンタープライズのコンプライアンス対応がさらに容易になった。

AWS
週次アップデート 2026-10-30
AWS サーバーレス週次ハイライト（10/24〜10/30）：IAM Identity Center が EventBridge 変更通知に対応、Lambda Durable Functions がライブテレメトリー出力を追加、Agent Registry が4リージョン拡張
詳細を表示

2026年10月24〜30日のAWSサーバーレス分野の主なアップデートとして、Amazon IAM Identity Center の Identity Storeがユーザー・グループの追加・変更・削除イベントをAmazon EventBridgeにリアルタイム通知する機能が追加された。これにより、ID変更をトリガーとした自動プロビジョニングやSIEM連携が容易になる。また、AWS Lambda の Durable Functions（耐久性のある長時間実行）がライブテレメトリーを外部に出力できるようになり、複雑なワークフローの実行状態の可視化・デバッグが改善された。さらに、Amazon Bedrock Agent Registry が4リージョン追加対応し、AIエージェントのグローバル展開の選択肢が広がった。各機能の詳細はAWS公式ブログおよびWhat's New（aws.amazon.com/about-aws/whats-new）で確認できる。

Oracle / Oracle E-Business Suite
重要度 高 CVSS 9.8 悪用スキャン確認 2026-10-30
Oracle E-Business Suite の CVSS 9.8 未認証 SQL インジェクション（CVE-2026-101767）、パッチ公開7日で実機への悪用スキャンが多発 ─ EBS 12.2.3〜12.2.15 が対象、即時パッチ適用を推奨
詳細を表示

OracleがCritical Patch Update（CPU）で修正したOracle E-Business Suite（EBS）の重大脆弱性CVE-2026-101767（CVSS v3.1: 9.8）に対し、パッチ公開から約7日後の2026年10月27日にHorizon3.aiのデコイ環境で実際の悪用探索が確認された。対象はThin Client Framework（TCF）サーブレット（/OA_HTML/AppsTCFServer）で、認証なしでPOSTリクエストを送信するだけでSQL実行が可能になり、Concurrent Manager経由でOS側に/bin/shを起動する連鎖攻撃まで実証されている。影響バージョンはEBS 12.2.3〜12.2.15で、修正はApplication Object Library（AOL）パッチの適用。Oracle EBSは日本の大手製造・流通・金融企業にも広く導入されており、未適用のシステムは早急なパッチ適用が必要。デフォルトのEBS URLフィルターが脆弱なエンドポイントへのアクセスを許可しているため、WAFでの制限のみでは不完全であり完全な修正には必ずパッチ適用が必要。

Linux Kernel / Ubuntu
重要度 高 CVSS 9.8 遠隔root実行を実証 2026-10-30
Linux カーネルに CVSS 9.8 の重大脆弱性（CVE-2026-98432）─ MPTCP の Use-After-Free でAnthropicが Ubuntu 環境での認証不要遠隔 root 権限実行を研究環境で実証
詳細を表示

Linux カーネルのMultipath TCP（MPTCP）スタックに存在するUse-After-Free脆弱性CVE-2026-98432（CVSS v3.1: 9.8）が2026年10月30日に報告された。Anthropicのセキュリティ研究チームが、MPTCPを有効にしたUbuntuサーバー環境で認証不要のリモートroot権限実行（RCE）を研究用制御環境下で実証したとされる。上流（mainline）カーネルでは修正済みだが、UbuntuはLinux 5.6以降からMPTCPをデフォルト有効とするバージョンを提供しており、一部ディストリビューションでは修正パッチの適用が完了していない。クラウドやVPSでUbuntuを運用している組織はカーネルバージョンを確認し、`apt upgrade`などでセキュリティアップデートを適用することが推奨される。詳細についてはUbuntuセキュリティチームの公式アドバイザリおよびCVEデータベースを一次情報として確認されたい。
