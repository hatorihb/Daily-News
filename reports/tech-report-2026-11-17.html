Apache HTTP Server / CVE-2026-119618
重要度 高 2026-11-16
【Critical・認証不要RCE】Apache HTTP Server mod_http2 競合状態の脆弱性（CVE-2026-119618）— HTTP/2有効環境で遠隔コード実行の恐れ
詳細を表示

Apache HTTP Serverのmod_http2モジュールに競合状態（race condition）に起因する重大な脆弱性CVE-2026-119618が発見された。HTTP/2を有効化している環境において認証不要でリモートからコード実行が可能となる可能性があり、攻撃条件のハードルが低い。HTTP/2はApache 2.4.17以降で標準サポートされているため影響範囲は広く、パブリックインターネットに公開されているウェブサーバーは特に早急な対応が求められる。修正済みバージョンへのアップグレードまたは設定でHTTP/2を無効化する回避策の適用が推奨される。セキュリティ研究機関が11月16日の週次脅威レポートで本脆弱性を重要課題として取り上げている。
